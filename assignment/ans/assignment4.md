## 2. 解答下列问题

### (1) $n \times n$ 上三角矩阵以**列优先**方式存储到一维数组 `B`

**答：** 上三角矩阵中，当 $i > j$ 时 $a_{ij} = 0$；当 $i \leq j$ 时 $a_{ij}$ 为非零元素。

以**列优先**方式存储到一维数组 `B`（从 0 号单元开始）：

- 第 1 列（$j=1$）：有 1 个元素（$a_{11}$）
- 第 2 列（$j=2$）：有 2 个元素（$a_{12}, a_{22}$）
- $\cdots$
- 第 $j-1$ 列：有 $j-1$ 个元素

第 $j$ 列前面共有 $1 + 2 + \cdots + (j-1) = \frac{j(j-1)}{2}$ 个元素。

在第 $j$ 列中，$a_{ij}$（$1 \leq i \leq j$）前面有 $i-1$ 个元素。

**因此，$a_{ij}$ 在数组 `B` 中的存储位置为：**

$$k = \frac{j(j-1)}{2} + (i - 1)$$

其中 $1 \leq i \leq j \leq n$。

### (2) 三对角矩阵 $A_{n \times n}$，三条对角线元素存入 `B[3n-2]`

三对角矩阵中只有主对角线、上对角线和下对角线上的元素非零，即 $|i - j| \leq 1$。

**① 用 $i,j$ 表示 $k$（统一公式）：**

以行为主序，第 $i$ 行前面共有元素：
- 第 1 行：2 个
- 第 2 行到第 $i-1$ 行：每行 3 个
- 总计：$2 + 3(i-2) = 3i - 4$（当 $i \geq 2$）

在第 $i$ 行中，$a_{ij}$ 的位置偏移：
- $j = i-1$（下对角线）时，偏移为 0
- $j = i$（主对角线）时，偏移为 1
- $j = i+1$（上对角线）时，偏移为 2

即偏移为 $j - i + 1$。

因此，统一公式为：

$$k = (3i - 4) + (j - i + 1) = 2i + j - 3$$

其中 $1 \leq i, j \leq n$ 且 $|i - j| \leq 1$。

**验证：**
- $a_{11}$（$i=1, j=1$）：$k = 2 \times 1 + 1 - 3 = 0$ ✓
- $a_{12}$（$i=1, j=2$）：$k = 2 \times 1 + 2 - 3 = 1$ ✓
- $a_{21}$（$i=2, j=1$）：$k = 2 \times 2 + 1 - 3 = 2$ ✓
- $a_{22}$（$i=2, j=2$）：$k = 2 \times 2 + 2 - 3 = 3$ ✓
- $a_{23}$（$i=2, j=3$）：$k = 2 \times 2 + 3 - 3 = 4$ ✓

**② 用 $k$ 表示 $i,j$（逆变换）：**

由 $k = 2i + j - 3$ 且 $j \in \{i-1, i, i+1\}$，可得 $k \in \{3i-4, 3i-3, 3i-2\}$。

令 $i = \left\lfloor \frac{k+1}{3} \right\rfloor + 1$，则 $j = k - 2i + 3$。

**验证：**
- $k=0$：$i = \lfloor 1/3 \rfloor + 1 = 1$，$j = 0 - 2 + 3 = 1$ → $a_{11}$ ✓
- $k=1$：$i = \lfloor 2/3 \rfloor + 1 = 1$，$j = 1 - 2 + 3 = 2$ → $a_{12}$ ✓
- $k=2$：$i = \lfloor 3/3 \rfloor + 1 = 2$，$j = 2 - 4 + 3 = 1$ → $a_{21}$ ✓
- $k=5$：$i = \lfloor 6/3 \rfloor + 1 = 3$，$j = 5 - 6 + 3 = 2$ → $a_{32}$ ✓

### (3) 稀疏矩阵的三元组表和十字链表存储表示

**三元组表（以行为主序，记录每个非零元素的行号、列号、值）：**

三元组顺序表用一个结构体数组存储，每个元素包含 `(row, col, val)` 三个字段。

```cpp
struct Triple {

    int val;

struct TSMatrix {
```

### (4) 数组 $a[n][2n-1]$ 的三角形存储（对应图 4-29）

图 4-29 所示为一个下三角形区域，三个顶点分别为 $a[0][n-1]$、$a[n-1][0]$、$a[n-1][2n-2]$。

该三角形区域可理解为一个下三角矩阵，元素 $a[i][j]$ 满足 $i + j \geq n - 1$ 且 $j - i \leq n - 1$（即位于下三角范围内）。

将其按行优先存入一维数组 $B[\frac{n(n+1)}{2}]$ 中时：

- 第 0 行（$i=0$）：有 1 个元素
- 第 1 行（$i=1$）：有 2 个元素
- $\cdots$
- 第 $i-1$ 行：有 $i$ 个元素

前 $i$ 行共有 $1 + 2 + \cdots + i = \frac{i(i+1)}{2}$ 个元素。

**$a[i][j]$ 到 $B[k]$ 的下标变换公式：**

$$k = \frac{i(i+1)}{2} + (j - (n - 1 - i))$$

其中 $0 \leq i < n$，$n - 1 - i \leq j \leq n - 1 + i$（在给定三角范围内）。

## 3. 算法设计

### (1) 判断模式是否为两个主串的公共子序列

**题目要求：** 给定模式串 `pattern` 和两个主串 `text1`、`text2`，判断 `pattern` 是否同时是 `text1` 和 `text2` 的公共子序列。

**思路：** 先判断 `pattern` 是否为 `text1` 的子序列，再判断是否为 `text2` 的子序列。若两者都是，则 `pattern` 是两主串的公共子序列。

判断一个字符串是否为另一个字符串的子序列，可用贪心双指针法，时间复杂度 $O(n)$。

```cpp
#include <cstring>

// 判断 pattern 是否为 text 的子序列
bool isSubsequence(const char* text, const char* pattern) {
    int i = 0, j = 0;
    while (text[i] != '\0' && pattern[j] != '\0') {
        if (text[i] == pattern[j]) {
            j++;
        }
        i++;
    }
    return pattern[j] == '\0';  // pattern 中所有字符都被匹配
}

// 判断 pattern 是否为 text1 和 text2 的公共子序列
bool isCommonSubsequence(const char* text1, const char* text2, const char* pattern) {
    return isSubsequence(text1, pattern) && isSubsequence(text2, pattern);
}
```

**时间复杂度：** $O(|text1| + |text2|)$，空间复杂度：$O(1)$。

### (2) 矩阵鞍点——行最小且列最大的元素

**思路：** 先找每行的最小值及其列号，然后检查该元素是否为其所在列的最大值。

```cpp
#include <iostream>
using namespace std;

void findSaddlePoint(int A[][100], int m, int n) {
    for (int i = 0; i < m; i++) {
        // 找第 i 行的最小值及其列号
        int minCol = 0;
        for (int j = 1; j < n; j++) {
            if (A[i][j] < A[i][minCol]) {
                minCol = j;
            }
        }

        // 检查该元素是否为其所在列的最大值
        bool isSaddle = true;
        for (int k = 0; k < m; k++) {
            if (A[k][minCol] > A[i][minCol]) {
                isSaddle = false;
                break;
            }
        }

        if (isSaddle) {
            cout << "鞍点: A[" << i << "][" << minCol << "] = " << A[i][minCol] << endl;
        }
    }
}
```

**时间复杂度：** $O(m \times n)$（每行找最小值 $O(n)$，验证是否为列最大值 $O(m)$，共 $m$ 行）
**空间复杂度：** $O(1)$

### (3) 判定元素 `x` 是否在特殊矩阵 $A$ 中

**题目条件：** 矩阵 $A$ 满足 $A[i][j] \leq A[i][j+1]$（每行递增）且 $A[i][j] \leq A[i+1][j]$（每列递增）

**思路：** 从右上角（或左下角）开始搜索。若当前元素大于 `x`，向左移动；若小于 `x`，向下移动。

```cpp
bool searchMatrix(int A[][100], int m, int n, int x) {
    int i = 0, j = n - 1;  // 从右上角开始
    while (i < m && j >= 0) {
        if (A[i][j] == x)
            return true;
        else if (A[i][j] > x)
            j--;  // 当前元素太大，向左移动
        else
            i++;  // 当前元素太小，向下移动
    }
    return false;
}
```

**时间复杂度：** $O(m + n)$，每次比较后要么下移一行，要么左移一列。
**空间复杂度：** $O(1)$
